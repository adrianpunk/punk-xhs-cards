# 自适应主题系统

## 主色来源

优先从 `character-card-pose.png` 中选择：

1. 上装的主要颜色；
2. 明显配件或个人品牌色；
3. 角色中面积较大的非肤色、非黑白灰颜色。

运行：

```bash
python3 scripts/derive_palette.py \
  --image <character-card-pose.png> \
  --out <theme.json> \
  --profile-name "<昵称或品牌名>" \
  --handle "<可选账号>"
```

用户指定主色时追加 `--accent '#RRGGBB'`。

Punk 的红色只属于 Punk profile。其他用户必须从其人物上装、稳定配件或明确品牌色重新生成主题，不继承红色模板。

## 颜色传播

同一个 `theme.json` 必须驱动完整交付：

- 封面：书脊、下部大色块、切角区域、分隔线与作者标记；
- Hero：唯一彩色玻璃或材质，禁止图像模型擅自换成绿色、蓝紫或 Punk 红；
- 内页：侧边线、页码、标签、重点框、分隔线和浅色 panel；
- 发布系列：同一人物的不同文章继续使用已确认 profile，除非用户明确更换品牌色。

不允许封面使用人物主色、Hero 使用另一种强调色、内页再回到固定模板色。

## 色阶

`theme.json` 包含：

- `accent`：侧边线、编号和重点结构；
- `deepAccent`：强调文字；
- `panel`：重点框浅色背景；
- `paper`：正文暖白或带轻微主色色相的背景；
- `ink`：标题；
- `body`：正文；
- `muted`：页码和账号；
- `line`：分隔线。

只允许一个主强调色。卡片不能同时堆叠多种高饱和颜色。

## 后备处理

图片只有黑、白、灰或肤色时，脚本会使用中性灰褐后备色并把 `source` 标记为 `fallback`。此时必须展示样稿并请用户选择或确认主色，不得宣称颜色来自人物，也不得默认回退到 Punk 红。

## 可读性

- 标题和正文始终使用深色，不用主色直接承载大段正文。
- panel 必须是 accent 的浅色阶。
- paper 接近白色，保持素雅。
- 主色过亮时自动压暗；过灰时自动提高饱和度。
