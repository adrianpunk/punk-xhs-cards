# Hero 纯图固定提示词

把花括号字段填完整后直接调用图像生成工具。不要把模板字段原样发送，也不要追加第二套风格。

```text
你是一位高级商业科技媒体的视觉总监。请根据下面的主题，生成一张高级、极简、可读的编辑视觉纯图。

用途：小红书竖版书封面中的 Hero 图
主题：{完整文章主题或封面标题}
画幅比例：严格 16:9 横版
核心关系 / 变化：{文章真正表达的关系、变化或结果}
核心动作：{连接、汇聚、对齐、推进、拆解、穿透、折叠、平衡、转化、生长或跨越中的一个}
抽象装置隐喻：{用一句话说明少量物体如何完成核心动作}
强调色：{来自 card profile 的强调色名称和十六进制值}
深强调色：{来自 card profile 的深强调色名称和十六进制值}

先理解主题背后真正要表达的关系、变化、动作或结果，再把它转译成一个“可读但不直白”的抽象实体意象。

- 画面只使用一个清晰核心动作。
- 物体之间必须有明确隐喻关系，让观众不看文字也能感到某件事正在发生。
- 只讲一个视觉故事，使用少量精确物体，不堆砌概念。
- 不把主题直接画成图标、说明书或字面场景；把它做成有材质、有结构、有动作的抽象小型装置。
- 不加入人物，人物 IP 将由外部排版层单独添加。

固定视觉语言：

- 高级商业编辑视觉、现代瑞士平面设计、克制的科技杂志感。
- 背景为暖白、米白，带极轻微纸张纹理。
- 中性材质仅使用哑光石墨金属、精密黑色模块和炭灰结构。
- 唯一彩色材质使用低饱和、半透明或磨砂的强调色玻璃；不得擅自加入绿色、蓝紫或第二种品牌色。
- 使用柔和自然棚拍光、细腻接触阴影和克制反射。
- 构图安静、精确、有留白，像画廊中的编辑雕塑；主体具有足够视觉重量，不做细长条。
- 画面必须为完整 16:9，不通过拉伸、压扁或加空白边框凑比例。

严格文字禁令：图片中不得出现任何可读文字、汉字、字母、数字、标题、Logo、水印、刊头、品牌、UI 标签、装饰性小字或伪文字。所有物体表面保持无字、无标识。

禁止赛博朋克、霓虹、蓝紫渐变、机器人、AI 大脑、芯片、科幻城市、复杂仪表盘、满屏 UI、卡通、家居风、廉价 3D、夸张光效、股票大屏、握手照、办公人物、PPT 模板感、课程封面感、电商广告感和多个互相争抢的概念。

只生成一张最终纯图，不输出解释、备选方案、网格、接触表或多方案拼图。
```
