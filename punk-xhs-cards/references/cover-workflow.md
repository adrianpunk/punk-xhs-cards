## 标题、作者与主题色

运行 `scripts/parse_markdown.py`。解析器只输出标题、正文和图片清单，不输出作者。

标题优先级：

1. YAML frontmatter 的 `title:`；
2. 第一个 `# 一级标题`。

完整阅读文章后拟定封面标题。封面标题不需要复制完整长标题；优先提炼成 8–18 个中文字的短书名，保留核心对象和动作。只在必要时排两行，不添加原文没有的数据、收益或承诺。

作者只从当前已确认 card profile 的 `author_name` 读取。Markdown 中即使存在 `author:`、`作者：` 或“关于作者”小节，也不得覆盖封面作者。

主题色优先读取人物创建阶段指定的 `theme_color`，并通过 `theme.json` 的 `accent` 使用；用户未指定时，从人物服装或配件提取候选色并在样稿阶段确认。`deepAccent` 用于标题文字与细节。

## IP 主题插图

必须完整遵循已安装的 `$punk-ip-article-illustrations` Skill。Punk XHS Cards 只提供“封面唯一认知锚点”的范围约束，不复制或削弱它的人物身份、文章理解和质量检查规则。

1. 完整读取 Markdown，提炼一个能代表全文的核心判断、结构或流程。
2. 使用当前已确认人物的干净参考图与 `character-spec.md`。
3. 根据内容选择“核心动作”或“流程拆解”。人物必须参与核心关系，保持脸、服装、配件与自然比例。
4. 生成一张 16:9 横版插图，保存为 `cover-illustration.png`。
5. 插图不包含封面大标题、作者、页码、品牌、Logo 或账号；这些由渲染器处理。
6. 发现人物比例、身份、动作或文章关系错误时，按个人 IP 插图 Skill 的单问题重试顺序修订。

封面只需要一张主题插图。不要按长文信息密度自动生成多张封面候选；正文是否另配插图由用户另行要求。

## 确定性封面版式

最终封面固定为 1080×1440：

- 整页背景使用 profile 的 `accent` 主题色。
- 顶部不放任何标题框。只排一个简短标题，使用圆润、略带亲和感的字体、暖白色、水平居中。
- 中间放 960×620 的 macOS 窗口，带细腻投影、轻边线、圆角、62 px 工具栏和红黄绿系统圆点。
- 工具栏下方保留完整 16:9 图片区，插入 `cover-illustration.png`；不加网址、浏览器品牌、伪文字、多余网页留白或 4:3 内容画布。
- 窗口下方只写 profile 的 `author_name`，使用粗体衬线字体居中。不显示 `AUTHOR`、“作者”、横线、花体签名或倾斜变形。
- 不显示页码、总页数、栏目名、品牌名或账号。

`cards.json` 新格式：

```json
{
  "cover": {
    "title": "完整封面书名",
    "illustration": "cover-illustration.png"
  },
  "cards": []
}
```

不得写 `cover.author`。渲染器从 profile 读取 `author_name`。旧版 `hero` 与 `artwork` 只为历史项目保持读取兼容，新文章不得继续创建。

## 确认门

先展示：

1. 16:9 IP 主题插图；
2. 1080×1440 最终封面；
3. 标题、profile 作者名和主题色 Hex。
